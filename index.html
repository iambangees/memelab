Stickers are exported at 512×512 WebP — WhatsApp's own format and size.

  1. Download the sticker file above.
  2. Open any WhatsApp chat, attach the file and send it.
  3. Tap the sticker → Add to favourites (⭐). Done — it lives in your sticker tray.
  4. Newer WhatsApp versions can also make stickers directly: long-press a photo in a chat → Create sticker.

MemeLab is a static page: no uploads, no accounts, no tracking. Animated GIF → *animated* sticker isn't possible in a plain browser (WhatsApp's animated format needs an encoder a web page doesn't have) — so GIFs become stickers from a frame you choose. Built by Bangees.
